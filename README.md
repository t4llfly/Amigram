# 📱 Amigram
**Native Telegram MTProto 2.0 Client for Windows Phone 8.1**

> [!WARNING]
> Проект тестировался лишь на смартфоне Nokia Lumia 930 и подтвержденно работает именно на нем. В приложении не реализовано множество функций и их стабильность не подтверждена, потому что проект создавался для личного использования. Так же отвечаю здесь, что код был создан нейросетью Gemini 3.7 Flash + Claude Sonnet 5 по причине нецелесообразности изучения и самостоятельной разработки на API Silverlight и старых версий C#. 

Amigram — это легковесный нативный клиент Telegram для устройств под управлением **Windows Phone 8.1 (Silverlight)**, разработанный специально для работы на смартфонах уровня Nokia Lumia 930 (Snapdragon 800).

Клиент работает **напрямую с серверами Telegram (DC1–DC5)** по зашифрованному протоколу MTProto 2.0 без использования сторонних прокси, промежуточных серверов или веб-оберток.

---

## ✨ Ключевые возможности

* **Нативный MTProto 2.0 Core:**
  * Прямое асинхронное TCP-соединение через `StreamSocket`.
  * Криптография: AES-256 IGE, SHA-256 KDF, Diffie-Hellman 2048-bit Handshake с современным `RSA_PAD`.
  * Полная поддержка двухфакторной аутентификации (**2FA Cloud Password**) на базе протокола **SRP-6a** (PBKDF2-HMAC-SHA512).
* **Каноничный дизайн Metro UI (Windows Phone 8.1):**
  * Панорамный интерфейс `Pivot` (Чаты, Контакты, Настройки).
  * Глубокий AMOLED черный фон (`#000000`) для экономии батареи и идеального контраста.
  * Аппаратный отклик при касаниях (**3D Tilt Effect**) со скоростью 60 кадров/сек.
  * Плавные анимации переходов страниц (`TurnstileNavigationTransition`).
* **Диалоги и переписка:**
  * Быстрый список чатов на базе аппаратного `LongListSelector`.
  * Поддержка закрепленных диалогов (Pinned Chats) и счетчиков непрочитанных.
  * Отправка и прием текстовых сообщений с индикацией статусов (`🕒`, `✔`, `✔✔`).
  * Контекстное меню (Long-Press): копирование текста, удаление сообщений для себя и для всех.
* **Медиа и Фотографии:**
  * Фоновая загрузка фото высокого разрешения (`upload.getFile`) с поддержкой межсерверного экспорта авторизации (`FILE_MIGRATE_X`).
  * Отправка снимков из системной галереи камеры (`PhotoChooserTask`).
  * Полноэкранный просмотрщик с аппаратным жестом **Pinch-to-Zoom (до 4x)** на GPU `BitmapCache` и сохранением в альбом «Сохраненные фото» (`MediaLibrary`).
* **Синхронизация и Live Tiles:**
  * Реальное время: фоновый опрос обновлений и удержание сокета через `updates.getState`.
  * Живая плитка (Flip Tile) на рабочем столе с числом непрочитанных сообщений.

## 🛠 Сборка и запуск проекта

### Требования:
1. **Visual Studio 2015** (Community / Professional / Enterprise) с пакетом **Update 3**.
2. **Windows Phone 8.1 SDK**.

### Настройка API ключей:
1. Зарегистрируйте приложение на [my.telegram.org](https://my.telegram.org) и получите персональные `api_id` и `api_hash`.
2. Скопируйте файл `AppConfig.example.cs` в `AppConfig.cs` и раскомментируйте его:
   ```csharp
   public const int ApiId = ВАШ_API_ID;
   public const string ApiHash = "ВАШ_API_HASH";
3. Соберите проект в режиме Release | ARM (для физического телефона Lumia) или Release | x86 (для эмулятора).
4. Разверните полученный файл Bin/Release/Amigram.xap на телефон через утилиту Windows Phone Application Deployment или WPInternals.
